MCP接続先の審査

生成AIを社外のMCPサーバにつなぐ前に、ツール定義と提供元の回答から、許可・条件付き許可・不可を判定します。

入力したJSONはこのブラウザの中だけで処理され、どこにも送信されません。審査対象のサーバにもアクセスしません。外部との通信は、解析エンジン（Pyodide）と文字フォントの読み込みだけです。

提出書類

  1. 接続先のツール名と説明文を貼る
  2. 分かる範囲で質問票に答える（分からない項目は空欄のままでよい）
  3. 「審査する」を押す

1. 接続先のツール

必須

提供元の資料やWebページに載っている、ツールの名前と説明文をそのまま貼り付けます。

JSONファイルがある場合・サンプルで試す

提供元から tools/list のJSONを受け取っている場合は、こちらから読み込むと引数の説明まで検査できます。

2. 質問票（提供元への確認）

任意

空欄の項目は「未確認」として、許可の条件に挙がります。

3. すでに使っている接続先

任意・複数可

他の接続先のツールを乗っ取る記述がないか照合します。過去にこの画面で保存した「承認用の固定ハッシュ」や、tools/list のJSONを選びます。

未指定

4. 承認したときの記録

任意

承認時に保存した固定ハッシュ（.pin.json）を選ぶと、承認後に定義が書き換えられていないかを照合します。

未指定

解析エンジンを読み込んでいます（初回は数秒〜十数秒かかります）

審査票

左でツール定義を入れて「審査する」を押すと、ここに判定が出ます。まずは「例：汚染された定義」で試せます。

判定はルールに基づく機械的なもので、最終的な承認は人が行います。ASI番号との対応は mcp-gate の設計上の割り当てで、OWASP公式の対応表ではありません。 ツールの annotations は提供元の自己申告であり、安全性の保証ではありません。
